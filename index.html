KaniTTS

A high-fidelity Text-to-Speech model running in your browser.

Try it live!

Overview

KaniTTS uses a two-stage pipeline combining a large language model with an efficient audio codec for exceptional speed and audio quality. This demo utilizes a similar architecture adapted for the browser, achieving extremely low latency for real-time applications.

Key Specifications:

  • Model: microsoft/speecht5_tts (adapted for browser)
  • Sample Rate: 16kHz
  • Languages: English
  • Technology: Transformers.js

Use Cases

  • Conversational AI: Real-time speech for chatbots and virtual assistants.
  • Accessibility: Screen readers and language learning applications.
  • Client-Side Processing: Secure, private TTS without server-side computation.

Responsible Use

This technology should be used responsibly. Prohibited activities include generating harmful or misleading content, hate speech, harassment, or impersonating individuals without consent.
